# CinemaVerse / CineFlix

Proyek ini adalah mockup aplikasi streaming film premium dengan tampilan modern dan nuansa Netflix-inspired.

## Fitur utama
- Landing page cinematic
- Film detail page
- Series page
- Genre browsing
- Search page
- Watchlist lokal
- Profile page
- Login/register page
- Subscription page
- Admin dashboard page

## Cara menjalankan
Buka folder `projectBioskop` dan jalankan server statis, misalnya:

```bash
cd e:/Vscode/projectBioskop
python -m http.server 8000
```

Lalu buka browser ke:

```text
http://127.0.0.1:8000/index.html
```

## Catatan
Ini adalah prototype front-end. Fitur autentikasi, database, dan video streaming real belum diintegrasikan ke backend produksi.
